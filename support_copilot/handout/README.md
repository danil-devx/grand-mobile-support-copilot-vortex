# Support Copilot — данные кейса

Анонимизированные обращения игроков Grand Mobile и ответы администраторов. Два вида обращений:

- **complaint** — жалоба на игрока из лаунчера за август–октябрь 2026: текст жалобы, иногда комментарий обвиняемого, ответ администратора с вердиктом.
- **report** — короткий внутриигровой репорт за последние 14 дней: вопрос или просьба игрока и ответ администратора из игры.

| Файл | Что это |
|---|---|
| tickets_train.jsonl.gz | 118 337 обращений: 67 755 жалоб и 50 582 репортов. Это все обращения случайно выбранных 20% заявителей, поэтому серии повторных жалоб одного игрока сохранены целиком |
| tickets_valid.jsonl | 1 000 обращений того же формата, выделенных для валидации. Категории и приоритета нет, вердикт и наказание из ответа администратора есть |
| rules.json | Правила игры с разбивкой на пункты. Поле `points[].ref` это идентификатор пункта для цитирования |
| taxonomy.json | Категории и приоритеты обращений с описаниями и примерами |

## Схема записи

```json
{
  "ticket_id": "5b2e…",
  "kind": "complaint",                      // complaint | report
  "created_at": "2026-03-14T19:02:00",
  "region": "kz", "server_lang": "kk",      // сервер, на котором подано
  "lang": "ru",                             // язык текста игрока по эвристике: ru | kk | uz | en | es | pt | lat | und
  "reporter_hash": "a91c…",                 // кто подал
  "reported_hash": "7f3e…",                 // на кого (только complaint)
  "reported_nick": "Arman_Petrov",          // синтетический ник обвиняемого, одинаковый во всех жалобах на него
  "rule_refs_raw": "2.1",                   // что игрок написал в поле «пункт правил», как есть; часто «жб» или пусто
  "images_count": 2,
  "status": 2,                              // 0 создана, 1 комментарий, 2 рассмотрена
  "messages": [
    {"role": "player",          "ts": "…", "text": "оскорбил меня и семью, скрины есть"},
    {"role": "reported_player", "ts": "…", "text": "это была игра по роли"},
    {"role": "admin",           "ts": "…", "text": "Уважаемый Dias_Volkov, … жалоба получила статус | одобрена. Игрок Arman_Petrov получит: мут на 30 минут за оскорбление."}
  ],
  "verdict": "approved",                    // см. список ниже, извлечено из шаблона ответа админа
  "punishment": "мут на 30 минут",          // извлечено из ответа админа, если есть
  "violation": "2.1 ОП"                     // код или формулировка нарушения из ответа админа, если есть
}
```

Значения `verdict`: `approved` жалоба одобрена и игрок наказан, `rejected` нарушения нет, `need_evidence` нужны доказательства, `invalid_format` жалоба оформлена неверно, `duplicate` дубликат, `already_punished` игрок уже наказан, `appeal_approved` и `appeal_rejected` для жалоб на своё наказание, `closed` закрыта без объяснения, `other` шаблон не распознан. Коды вроде «2.1 ОП» означают пункт 2.1 общих правил, «GZ» правила зелёной зоны, «ЖБ» правила жалоб.

## Что сделано с текстом

- Имена персонажей заменены синтетическими, одинаковыми во всём наборе: жалобы на одного игрока остаются связанными между собой и с полем `reported_nick`.
- Ссылки, почта, хэндлы и последовательности из 7 и более цифр заменены токенами `<url>`, `<email>`, `<handle>`, `<digits>`. Номера жалоб в ответах админов тоже попали под эту замену.
- Скриншоты не выдаются, есть только их количество.

## Что важно знать

- Ответы администраторов на жалобы шаблонные. Шаблон содержит вердикт, наказание и формулировку нарушения: поля `verdict`, `punishment`, `violation` извлечены из него автоматически и могут использоваться как разметка исхода.
- Репорты короткие и часто без содержания: «помогите», «ау». Ответы на них тоже короткие. Это реальный поток, и его сортировка часть задачи.
- Тикетов поддержки из лаунчера в наборе нет.

## Условия использования

Данные выданы только для решения кейса в рамках Decentrathon 6.0. Запрещено пытаться деанонимизировать игроков, публиковать данные или их части, в том числе в репозитории решения. Данные удаляются в течение 14 дней после объявления победителей.
